## 1. 五项逐条

### S1 字体大小与行高

- 界面：字号 10/11/12/14/16/18 dp 六个档 ＋ 行高「舒适／紧凑」两档；当前值高亮。
- 落盘：`TerminalPrefs`（终端仓既有设施，本批只读写不扩语义）。
- 生效路径：值是 prefs，`TerminalActivity.onCreate` 里 `applyTo` ⇒ 下次「打开终端」就是新字号，**不用重启 App**（App 进程不变，只是重新起一个终端 Activity）。
- 门禁：`term_settings_*` 键被界面引用（`每条设置的文案资源都被界面引用`）。

### S2 重装 / 修复环境（二次确认）

- 只读展示：环境版本（debian-13.7）、环境指纹、安装时间、占用体积、本地安装包大小。
- 按钮 → `ReinstallGate.decide(installing, archiveBytes, confirmed)`：没确认恒为 `NeedConfirm`、没有本地包出「没有本地安装包」、安装中出「已有任务在跑」。
- 确认弹窗写明"用本地安装包（190.9 MB）重新解压系统层，约几分钟；home 里的用户数据不受影响"。
- 执行链**全部复用公开入口**：`RootfsInstaller.install(...)`（内部自带 `withInstallLock`）→ `RootfsCache.pruneKeep` → `RootfsState.markInstalled()` → `SessionManager.kill(app)`（换树后旧会话跑的是作废的那棵，与终端页 `relaunchDebian` 同口径）→ `InstallFlow.finish`。
- 进度不另做一套：页面上直接渲染 `InstallFlow.StatusLine()`（单一状态 + 通知栏）。
- 门禁：`重装只走 InstallFlow 与 RootfsInstaller 的公开入口` 禁止出现 `installInto(` / `extractArchive(` / `swapIntoPlace(` / `withInstallLock(` / `InstallProgress.`。

### S3 清缓存（只清 cache 与残件，不动 rootfs）

- 清理对象（`CachePlan.targets` 白名单）：`cache/` 本体子项、Agent 包缓存（`CacheCleaner.cleanAgentCaches`）、`rootfs/tmp` 里**有指纹**的残件（`CacheCleaner.cleanTempFiles`）、安装包缓存里非当前的归档与 `.part` 残片（`RootfsCache.cleanupNonCurrent`）。
- 安全边界：`CachePlan.isSafeTarget` 拒绝任何落在 `files/rootfs` 里的路径、拒绝 `filesDir` 与 `cacheDir` 本身；`白名单里没有任何 rootfs 路径`、`rootfs 本体与它的系统子目录都不是安全目标` 两条用例钉住。
- 显示：清理前后各量一次，差值为释放量，`已释放 %1$s`（`formatMb` 一位小数）。

### S4 镜像与源（只读展示＋覆盖）

- 只读：从环境的 `sources.list` 取**第一条 deb 行的 URI**、从 `pip.conf` 取 `index-url`（解析器在 `TermSettingsLogic`，带方括号选项/行尾注释都能取）。
- 覆盖：填 apt/pip 后写 home 层（`home/.zhengdao/env.sh` ＋ 托管块写进 `home/.profile`，`APT_CONFIG`/`DIR::ETC::SOURCELIST`/`PIP_INDEX_URL`），**rootfs 里的文件一个都不碰**；apt 那份 `sources.list` 由环境里那份**只换 URI** 得到（suite 与注释原样保留）。
- 环境没装时 apt 输入框禁用（第二道闸在 `saveMirrorOverride`）。
- 门禁：托管块幂等（`托管块重复写入是幂等的，且不动块外内容`）、空值不生成导出（`两项都空就不生成任何导出`）。

### S5 关于

- 显示 `BuildConfig.VERSION_NAME` / `APPLICATION_ID` / 随包许可证。
- 门禁四条：`版本号与应用 ID 跟 build_gradle_kts 一致`（直接解析 `app/build.gradle.kts`，不是手抄）、`随包许可证副本必须与仓根同名文件一致`、`设置页中英文案键一致`、`设置页源码的字面量里没有中文`。

1. **清缓存的"已释放 X MB"没拍到**：这台机器上缓存是 0（页面显示"没有可清理的缓存"），按下按钮只会得到"已释放 0.0 MB"。要拍到非零数字得先造一份符合指纹的残件（`rootfs/tmp` 下 `mat-debug-*.log` 且 mtime 早于 24 小时），而那一刻手机已经被终端 1 拿走（01:06:54 换包），**我没有再去抢**。释放量的算术与白名单由 18 条逻辑用例 ＋ 负例③钉住。

3. **没按"确认重装"**：真机只证到"弹窗＋取消"；"复用现有安装流程"是代码＋门禁证据（负例⑤反钉：绕开公开入口立刻红）。
